# **App Name**: Knowledgeable

## Core Features:

- User Profile: User profile with displayed list of currently reading, previously read books and uploaded summaries and questions. They may also upload research they conducted, opinions and commentary on current reading.
- Content Feed: Display uploaded books and their summaries, book notes, teachings, scholarly articles, research papers, their summary, ideas, discussions, and questions.
- Follow Feature: Ability to 'follow' other users.
- AI Question Generator: AI-powered tool that can automatically generate questions or discussion points from a given book summary or specific book chapters/pages.
- Text Editor: Text editor that allows a user to summarize a document or book, to initiate a documentary about the topic or to prepare a question for discussion.
- Search: Implement a simple search functionality to find specific books, articles, news or users within the platform.

## Style Guidelines:

- Background color: Light desaturated blue (#E8F0FE) to provide a calm and focused environment for reading and learning.
- Primary color: Muted blue (#5C87B2), a versatile color that is neither too vibrant nor too dull, creating a balance for the user.
- Accent color: Pale Yellow (#B2A65C). It provides a visual cue that is noticeable yet does not disrupt the overall aesthetic. Add feature to personalise and customize the colors of the app should the user not like default combination
- Add dark mode
- Clean and readable font for body text. Add ability to change font size
- Slightly bolder font for headers.
- Use consistent and simple icons for navigation and interaction.
- Clean and intuitive layout that is similar to other well-known social media to improve user experience
